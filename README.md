# austinbasswork.github.io

The root of `https://austinbasswork.github.io/`, published by GitHub Pages. It holds only the files that must sit at the website's root:

- `.well-known/apple-app-site-association`: lets Radon Tracker on iPhone open shared-detector links (`/Radon-Tracker/add/…`) directly, in one tap.
- `.nojekyll`: makes GitHub Pages publish the `.well-known` folder.

The source of these files is `store/website-root/` in [Radon-Tracker](https://github.com/AustinBassWork/Radon-Tracker) (see its `docs/SHARE_LINKS.md`). The privacy policy, support and add pages are published separately, from that repository, at `/Radon-Tracker/`.
